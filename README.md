Dala — Your team’s second brain

Live demo (local): run `npm run dev` inside the dala-app folder and open http://127.0.0.1:5173

Short description
-----------------
Dala connects the ideas, people, and decisions already inside your team and surfaces them as a shared, searchable intelligence. This landing page is a handcrafted, human-designed front-end built with React + Vite.

What's included
---------------
- Responsive landing page with an animated 3D-like brain illustration (SVG + CSS)
- Handcrafted UI and motion (no generative models used to write the site)
- Search demo that shows example signals from team knowledge

How to publish to GitHub (create the remote repository first)
-----------------------------------------------------------
1. Create a repository on GitHub (use your account): https://github.com/youssefamr2772006-sys
2. From the dala-app folder locally, run:

   git init
   git add .
   git commit -m "Initial Dala landing page — handcrafted"
   git branch -M main
   git remote add origin https://github.com/youssefamr2772006-sys/dala-app.git
   git push -u origin main
